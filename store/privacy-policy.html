DualTouch 개인정보처리방침

시행일: 2026년 11월 20일 · 적용 앱: DualTouch (com.hebi.dualtouch) · 운영자: hebi

이 방침은 DualTouch Android 앱의 데이터 처리에 적용됩니다. DualTouch는 사용자가 직접 승인한 좌우 분할 앱 창 사이에서 단일 탭을 재현하는 도구입니다. 장애인 직접 지원을 주목적으로 하는 접근성 도구로 표시하지 않습니다.

1. 기기 안에서 일시 처리하는 정보

사용자가 인앱 고지에 동의하고 Android 접근성 서비스를 직접 활성화하면, 앱은 현재 창의 패키지명·창 식별자·디스플레이·위치·크기·포커스 상태를 확인합니다. 실행 중 터치 좌표·시각과 손가락 수를 일시 처리하고, 키보드·비밀번호 및 입력 화면 차단을 위해 접근성 노드의 비밀번호·편집 가능·포커스 등 구조적 속성을 확인합니다. 화면 텍스트·계정정보를 분석하거나 스크린샷·영상·음성을 기록하지 않습니다.

이 정보는 사용자가 승인한 두 창의 확인, 좌표 변환, 가상 탭 요청과 위험 상태에서의 중단에만 사용합니다. 접근성 데이터와 터치 기록은 파일에 영구 저장하거나 외부로 전송하지 않습니다. 승인한 두 창 정보는 현재 서비스 세션의 메모리에만 유지합니다.

2. 기기에 저장하는 설정

Thumb 및 기준점의 크기·색상·투명도, 방향별 정규화 영점 보정값, 마지막 방향, 소개 확인 여부, 접근성 고지 동의 여부를 앱 전용 저장소에 저장합니다. 자동 입력 실행 상태와 앱 연결 승인은 재시작 후 자동 복원하지 않습니다. Android 앱 데이터 삭제 또는 앱 삭제로 로컬 설정을 지울 수 있습니다. 앱은 Android 자동 백업을 사용하지 않습니다.

3. 수집·공유 및 외부 서비스

현재 앱에는 인터넷 권한, 광고·분석·충돌보고 SDK, 로그인·계정·결제·클라우드 서버가 없습니다. 앱이 접근성 데이터·기기 식별자·개인정보를 개발자나 제3자의 서버로 수집·판매·공유하지 않습니다. Google Play와 Android 운영체제가 자체적으로 처리하는 설치·보안·진단 정보에는 해당 서비스의 정책이 적용됩니다.

사용자가 이 공개 방침을 외부 브라우저로 열면 웹사이트 접속 정보가 해당 브라우저와 웹 호스팅에서 처리될 수 있습니다. 이 페이지를 제공하는 BlogFlow 웹사이트의 쿠키·접속통계 등은 BlogFlow 웹사이트 개인정보처리방침에 따르며, 앱이 터치나 화면 데이터를 웹사이트에 전달하는 기능은 없습니다.

4. 선택·동의 철회

동의하지 않으면 터치 연동 및 플로팅 제어를 시작하지 않습니다. 앱의 표시 설정 화면에서 접근성 사용 동의를 철회하면 입력 수신과 플로팅 표시를 즉시 중단합니다. Android 시스템에 허용한 접근성 서비스는 시스템 설정에서 별도로 끌 수 있습니다. 기본 OFF, 20초 자동 중지, 볼륨 아래 긴급 중지를 제공합니다. 실제 기기별 중지 동작의 검증 여부와 별개로, Android에 이미 전달한 한 번의 제스처를 소급 취소한다고 보장하지 않습니다.

5. 민감 화면과 기능 한계

금융·보안 앱으로 식별되는 패키지, 감지된 키보드·비밀번호·입력 화면·팝업 등에서는 입력을 차단하도록 설계했습니다. 공개 Android API만으로 모든 결제·송금·삭제·보안 화면을 완전히 식별할 수는 없습니다. 민감하거나 되돌리기 어려운 작업에는 사용하지 마세요. 실제 두 앱의 터치 성공·기기 호환성은 검증된 범위에서만 안내합니다.
