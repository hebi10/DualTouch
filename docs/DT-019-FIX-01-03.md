- DT-FIX-03: 콘텐츠 이벤트를 최대 32ms 단위로 묶되 창/포커스 이벤트는 즉시 처리합니다. 기존 256개 노드 한도와 전체 조회 500ms 예산을 유지/추가하며 조회 실패와 시간 초과는 차단합니다. Binder 호출 자체를 500ms 안에 강제로 취소하는 것은 아닙니다. 캡처 설정 실패는 논리 상태를 OFF로 전환하고 서비스 자체 해제를 시도하며 재활성화 안내를 표시합니다. 개인정보·터치 좌표 로그/영구 저장/외부 전송 추가 없음.
