계정·비밀번호·금융/결제·실제 거래 화면 촬영/시연 금지. 확인 가능한 개발용 시험 화면으로 차단 상태를 보여준다.
제출 영상은 실제 앱과 권한 사용을 숨기지 않고 동의/거절 흐름 및 핵심 기능을 모두 보여준다. 실제 기기 영상 파일·공개 시청 링크는 아직 없음. 촬영·업로드 완료로 표기하지 않음.
10. 서명·AAB·배포 상태
소스에 업로드 keystore/서명 설정/Play 게시 workflow 없음. 브라우저 GitHub 설정은 로그인되지 않아 Secrets 이름과 기존 업로드 키의 실제 보유 여부는 확인 불가. 키가 없다고 단정하거나 새 키를 생성하지 않음.
Play 앱 미생성으로 App Signing 등록 상태도 아직 없음. 실제 기존 키 유무/권한 확인 후 재사용 여부 결정.
서명 AAB 생성 0건, Play 업로드 0건, 내부 테스트 릴리스·테스터 목록·초대 링크 없음. 서명 AAB 생성과 내부 테스트 업로드는 각각 별도 승인, 조건 미충족 시 실행하지 않음.
Release APK의 서명 없는 컴파일 결과는 Play 제출용 AAB가 아니다.
11. 출시 차단과 다음 단계
P1-DT-INPUT: 실제 기기 양방향 30회씩 원본/상대창 각 1회·중복/오클릭/잔류/재귀 0회 미검증.
P1-DT-SAFETY: 긴급 중지·타이머·서비스 회수·키보드/민감 화면·접힘/회전·창 변경과 일반 터치 복구의 기기 검증 미완료. 모든 민감 화면 감지 불가라는 공개 API 한계.
등록 차단: 가격 결정과 생성 화면의 법적/정책 선언 확인. 서명 단계 차단: 기존 업로드 키 확인·재사용 및 별도 승인.
심사 자료 차단: 실제 기기 접근성 시연 영상 없음, 에뮬레이터 캡처 결과 검수 전.
순서: 최신 PR 자동 CI·실제 화면 자료 → 사용자 확인 후 Play 신규 초안 생성 및 자료 입력 → 실기기 기능/안전 QA 및 영상 → 검증된 변경만 병합 → 고정 main 전체 QA 1회 → 서명 AAB 승인·생성/검증 → 내부 테스트 업로드 승인·게시 확인.
현재 상태는 등록·검증 준비이며 출시 가능 또는 내부 테스트 배포 완료가 아니다.
