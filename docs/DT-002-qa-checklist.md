# DT-002 실기기 QA 체크리스트

상태: 미실행 — 실기기 테스트를 자동 CI로 대체하지 않습니다.

## 사전 확인

- [ ] 실제 Fold 모델 / Android API / One UI 버전 기록
- [ ] `app`, `probe-left`, `probe-right` APK 세 개 정상 설치
- [ ] 접근성 OFF 상태에서 동작하지 않음
- [ ] 하드웨어 볼륨 아래 비상 중지 확인
- [ ] 테스트 두 앱이 좌우 별개 창으로 5:5 표시됨
- [ ] 제어 앱을 떠나 테스트 창으로 돌아가는 동안 준비 상태 유지

## 모드별 테스트

| 모드 | 시도 | 좌측 정확히 1회 | 우측 정확히 1회 | 누락 | 중복 | 오터치 | 결과 |
|---|---:|---:|---:|---:|---:|---:|---|

## 안전 테스트

- [ ] 드래그·스크롤 중지 이후 원래 화면 조작 복원
- [ ] 두 손가락 입력에서 강제 중단
- [ ] 20초 후 실제 캡처 해제
- [ ] Fold 접기·화면 회전·분할 해제 시 즉시 종료
- [ ] 다른 앱으로 이동할 때 제스처가 전달되지 않음
- [ ] 접근성 권한 해제/서비스 종료 후 정상 입력
- [ ] 보호 대상이 아닌 시스템 앱에 입력 없음
- [ ] TalkBack 사용 중 입력 가로채기·제스처 충돌 여부 기록

## 기술 판정

- 최초 GO 기준(제안): 30회 중 양쪽 정확히 한 번씩 29회 이상 및 P0 안전 실패 0
- CONDI­TIONAL: 노드 클릭만 가능하거나 일부 UI에서만 반응(범용 제품으로 주장 금지)
