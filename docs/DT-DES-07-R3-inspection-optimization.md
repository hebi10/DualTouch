# DT-DES-07-R3 — Reduce window inspection overhead without relaxing safety

R2 CI 45543959049: build/test successful; isolated overlay test reached actual connected controller home, a visible Thumb, and two real split probe windows at 1680×1440. It failed at app connection: Timeout: explicit direction approval. The verified diagnostic shows the actual rejection "화면 구조 검사 시간이 초과되었습니다. 안전을 위해 입력을 중지합니다." Both probe counters were zero. The diagnostic is not a successful DES-08 capture. Other overlay designs remain unverified.

Observed implementation: observeWindows queried every window root with prefetch strategy 0, including non-app layers whose package identities are not consumed by either safety policy. Each application child was queried with strategy 0 under a shared 500ms deadline. This is a plausible contributor, not a measured root-cause timing breakdown.

- Query package identities only for application and accessibility-overlay layers, since the existing policies need those identities. Keep every window in geometry, focus, layer, obstruction, and safety checks. Missing app/overlay identity remains blocked.
- Request Android FLAG_PREFETCH_DESCENDANTS_HYBRID for application root and child lookups. See https://developer.android.com/reference/android/view/accessibility/AccessibilityNodeInfo#FLAG_PREFETCH_DESCENDANTS_HYBRID and https://developer.android.com/reference/android/view/accessibility/AccessibilityWindowInfo#getRoot(int). Do not assume prefetch returned all nodes: traverse every reachable child, retaining the 256-node cap, 500ms budget, sensitive-input checks, null/error fail-closed handling and existing dispatch rechecks. No uninterruptible prefetch, timeout increase, package exemption, or stale snapshot reuse.
- Add unit tests for package-identity requirements, unknown accessibility overlay blocking and unknown window blocking. Existing inspection timeout/sensitive/limit/obstruction tests remain.
- In isolated probe instrumentation, let the actual split settle and, only before approval, retry a visible inspection-timeout result using the existing "다시 검색" action at most twice. Do not retry incomplete or other safety failures; never automatically retry armed input. Require actual split and approval controls before saving a matching capture.

Production safety-related query path changed; real runtime performance and safety remain unverified until new CI and subsequent physical-device QA. No new runtime permissions, logs of screen data, release readiness changes, publishing, or merge. DES-04 remains a separate feasibility check.
