# DualTouch

Android 접이식 기기의 좌우 분할 창에서 한 번의 수동 터치를 두 독립 창에 적용하는 기능을 기술 검증하는 프로젝트입니다.

현재 단계: DT-002 기술 POC. Android 공개 API가 원본 터치를 차단하거나 기존 제스처를 취소할 수 있으므로 기기에서 검증하기 전에는 범용 터치 동기화를 보장하지 않습니다.

기획: https://docs.google.com/document/d/1iTtV9sP_YaZkVkYxD2Wf8OY6D1BiWLlzG-slIqnyf3Q/edit

Google Play 자동 배포 금지. 기술 검증 및 승인된 전체 QA 완료 후 릴리스 작업을 따로 수행합니다.
